# Travel Site

A simple static travel website built using HTML and CSS.

This project was created as a beginner-friendly web development project to practise building a multi-page website, styling pages with CSS, organising local image assets, and deploying a static website using GitHub Pages.

## Live Demo

This project is deployed using GitHub Pages.

Live site:

https://javen06.github.io/travel-site/

## Features

- Static multi-page website
- Home page
- About page
- Blog page
- Contact page
- Destination / travel guide page
- Shared CSS styling
- Local image assets
- GitHub Pages deployment
- Built without JavaScript or frameworks

## Tech Stack

- HTML
- CSS
- Git
- GitHub
- GitHub Pages

## How to Run Locally

Clone the repository:

    git clone https://github.com/javen06/travel-site.git
    cd travel-site

Open index.html directly in your browser.

Alternatively, use the Live Server extension in VS Code:

1. Open the project folder in VS Code.
2. Install the Live Server extension.
3. Right-click index.html.
4. Select "Open with Live Server".
